

CloudQuiz is a cloud-native online examination platform designed to conduct online quizzes, evaluate student submissions, and manage examination results using AWS cloud services.
Objectives
- Provide secure user registration and login.
- Allow students to participate in online quizzes.
- Automatically evaluate submitted answers.
- Store quiz questions and results in a cloud database.
- Provide administrators with quiz management functionality.
- Implement automated testing and CI/CD deployment.
Technology Stack
Component	Technology
Frontend	HTML, CSS, JavaScript
Backend	Python
Cloud Platform	AWS
Compute	AWS Lambda
API	Amazon API Gateway
Database	Amazon DynamoDB
Authentication	Amazon Cognito
Infrastructure	AWS SAM
Version Control	Git and GitHub
CI/CD	GitHub Actions
Monitoring	Amazon CloudWatch

Project Structure
- frontend/ – User interface
- backend/ – Python backend functions
- infrastructure/ – AWS infrastructure configuration
- .github/workflows/ – CI/CD workflows
- docs/ – Project and deployment documentation
